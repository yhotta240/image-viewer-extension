## Image Viewerとは

現在開いているWebページの画像を集め，ギャラリー形式で閲覧できるChrome拡張機能です．

画像がたくさん並んでいるページでも，画像を一枚ずつ別タブで開かずに，ページ内の画像をまとめて確認できます．

## 主な機能

- ページ内の画像をギャラリーで表示
- 左右キー・ボタン・スワイプで画像を切り替え
- クリック・ホイール・ドラッグで拡大・移動
- ホバー・Alt + クリック・右クリックから表示
- 画像のダウンロードと共有

導入手順，ビューアを開く方法，操作方法，設定については，[チュートリアル](tutorial.md)を確認してください．
