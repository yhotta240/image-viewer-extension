## Image Viewerとは

現在開いているWebページの画像を集め，ビューアでまとめて閲覧・保存できるChrome拡張機能です．

画像が多いページでも，別タブで1枚ずつ開くことなく，ビューア内で切り替えながら確認できます．

## 主な機能

- ページ内の画像をビューアで1枚ずつ表示
- 左右キー・ボタン・スワイプで画像を切り替え
- クリック・ホイール・ドラッグで拡大・移動
- 画像上のボタン・Alt + クリック・右クリックメニューから表示
- 画像のダウンロードと共有
- ギャラリー表示で画像を一覧確認

導入手順，ビューアを開く方法，操作方法，設定については，[チュートリアル](tutorial.md)を確認してください．
