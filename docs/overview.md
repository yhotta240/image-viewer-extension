## Image Viewerとは

Image Viewerは，現在のWebページにある画像をまとめて見やすく表示するChrome拡張機能です．

画像がたくさん並んでいるページでも，ページを何度も移動したり，画像を一枚ずつ別タブで開いたりせずに画像を順番に確認できます．

## 主な機能

- ページ内の画像をギャラリー表示
- 原寸画像を優先表示
- キー・ボタン・スワイプで前後移動
- クリック・ホイール・ドラッグで拡大操作
- ホバー・Alt + クリック・右クリックから表示
