# Image Viewer

現在のWebページにある画像を収集し，ギャラリーとして閲覧するChrome拡張機能です．

## 使い方

- 画像にホバーして表示されるボタンをクリック
- 画像上で Alt + クリック
- 画像を右クリックして「Image Viewerで開く」を選択

ビューアでは、左右キー・前後ボタン・スワイプで移動できます。画像クリックで拡大、ホイールでズーム、ドラッグでパンできます。Escまたは閉じるボタンで終了します。

ポップアップから、最小画像サイズ・CSS背景画像の収集・ホバー起動ボタンの表示を設定できます。

## 開発

```bash
npm install
npm run build
```

生成された `dist/` をChromeの「パッケージ化されていない拡張機能」として読み込んでください。
