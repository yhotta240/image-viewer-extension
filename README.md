# Image Viewer

現在開いているWebページの画像を集め，ギャラリー形式で閲覧できるChrome拡張機能です．

## 主な機能

- ページ内の画像をギャラリーで表示
- 左右キー・ボタン・スワイプで画像を切り替え
- クリック・ホイール・ドラッグで拡大・移動
- ホバー・Alt + クリック・右クリックから表示
- 画像のダウンロードと共有

## 使い方

- 画像にホバーして表示されるボタンをクリック
- 画像上で Alt + クリック
- 画像を右クリックして「Image Viewerで開く」を選択

詳しい導入手順，設定，操作方法は，[チュートリアル](docs/tutorial.md)を確認してください．

## 開発

```bash
npm install
npm run build
```

生成された `dist/` をChromeの「パッケージ化されていない拡張機能」として読み込んでください．
